# Weather App 

A dynamic weather application with real-time data, animated backgrounds, and interactive map.

## Features

- Real-time weather data from OpenWeatherMap API
- Animated backgrounds that change based on weather conditions (sun, clouds, rain, snow)
- Interactive map showing city location

## Technologies

- HTML, CSS, JavaScript
- OpenWeatherMap API
- Leaflet.js for maps

## Setup

1. Clone the repo
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
3. Copy `config.example.js` to `config.js` and add your API key
4. Open `index.html` in your browser

- How to make API calls with fetch() and work with JSON data
